📚 Clube de Assinatura — Encantos Literários

Landing Page | Front-end Development

Projeto de landing page responsiva desenvolvido para simular um produto digital real de um clube de assinatura literário. O foco está em UI/UX, estrutura semântica, organização de layout e comunicação orientada à conversão.

Este projeto integra meu portfólio como demonstração prática de habilidades em front-end, design de interfaces e pensamento estratégico de produto.

🧠 Contexto do Projeto

A proposta foi criar uma página institucional capaz de:

Comunicar valor de forma clara e persuasiva

Guiar o usuário por uma jornada lógica até a assinatura

Unir estética, storytelling e organização visual

Simular um cenário real de produto comercial

O projeto foi pensado como se fosse entregue a um cliente real, seguindo boas práticas de desenvolvimento e apresentação.

🎯 Objetivos Técnicos e de Produto

Estruturar uma landing page com HTML semântico

Desenvolver um layout responsivo e organizado

Trabalhar hierarquia visual e CTA estratégicos

Aplicar boas práticas de organização de arquivos

Criar uma base sólida para futuras evoluções (JS, backend, pagamentos)

🛠️ Tecnologias Utilizadas

HTML5 — Estruturação semântica e acessível

CSS3 — Layout, responsividade e estilização

Google Fonts (Raleway) — Tipografia moderna

SVGs e imagens otimizadas — Performance e qualidade visual

Projeto desenvolvido sem frameworks ou bibliotecas externas, reforçando domínio da base do front-end.
