# 📚 Clube de Assinatura — Encantos Literários

**Landing Page | Front-end Development**

Projeto de **landing page responsiva** desenvolvido para simular um produto digital real de um clube de assinatura literário.  
O foco está em **UI/UX**, **estrutura semântica**, **organização visual** e **comunicação orientada à conversão**.

Este projeto integra meu **portfólio profissional**, demonstrando habilidades técnicas e visão estratégica de produto.

---

## 🧠 Contexto do Projeto

A proposta foi criar uma página institucional capaz de apresentar um clube de assinatura literário de forma clara, atrativa e estratégica, simulando um cenário real de mercado.

O projeto foi desenvolvido como se fosse entregue a um cliente real, priorizando boas práticas de front-end, organização de código e experiência do usuário.

---

## 🎯 Objetivos do Projeto

- Estruturar uma landing page com **HTML semântico**
- Desenvolver um layout **responsivo e bem organizado**
- Trabalhar hierarquia visual e **CTAs estratégicos**
- Demonstrar domínio da base do front-end (HTML + CSS)
- Criar uma base escalável para futuras evoluções

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** — Estrutura semântica e acessível  
- **CSS3** — Estilização, layout e responsividade  
- **Google Fonts (Raleway)** — Tipografia moderna  
- **SVGs e imagens otimizadas** — Performance e qualidade visual  

> Projeto desenvolvido sem frameworks ou bibliotecas externas.
